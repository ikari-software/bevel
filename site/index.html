What it is

A whole shell, not a theme.

Bevel replaces the desktop, taskbar and file manager — each part built for real, and skinnable end to end.

Three skins, one shell

Switch eras, live

Windows 2000 by default, a glossy Luna (XP) variant, and a flat Whistler direction — swapped at runtime by two recolor engines, no restart.

A real Explorer

It actually manages files

Folder Options, show-hidden, extension handling, view styles and four functional sidebar eras from NT 4 through Windows 7 — a working file manager, not a screenshot.

Taskbar, Start & tray

Live window buttons

A Start menu, per-window task buttons, and a system tray that mirrors your macOS menu-bar extras with their real icons. Right-click a browser or terminal button to jump straight to any of its tabs — with their real favicons.

Pure vector, always

No bitmaps, ever

Every icon and control is code-drawn geometry bound to theme tokens — antialiased, Retina-crisp, and infinitely scalable.

Native underneath

macOS all the way down

A multi-process shell with sandboxed helpers, gRPC over Unix sockets, and AX + ScreenCaptureKit for genuine window and tray data.

Yours to shape

Scriptable & open

Drive it from the command line with bevelctl and bevel:// verbs. Open source, and built to be re-themed.
