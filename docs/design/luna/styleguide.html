Chrome anatomy

Caption — 25px tall, top corners rounded 8px, bottom square. Authentic Luna is a matte vertical gradient (soft top highlight → deep #003EC9 base) with a right-edge horizontal lightening — no wet-glass sheen (that specular gloss is a Royale/aftermarket trait).

Caption buttons — 21×21 glossy squares; the split-stop gradient gives the two-tone “shiny bead” look; close is red.

Start — asymmetric pill (square left, bulged right), green gloss over the top third, waving 4-colour flag, start set in Franklin-Gothic italic.

Every fill here is a vector gradient — no bitmaps — so it stays crisp at any scale and rebinds to theme tokens for the Avalonia port.
