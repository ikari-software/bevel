## REGRESSION — Win2000 border geometry (cite: commit `a967ec8`)

The geometry scouts confirmed it: **`a967ec8` ("fix(luna): title bar is the rounded top of the frame", 2026-07-25)** restructured `third_party/classic-avalonia/.../Styles/Window.axaml` so the caption docks full-bleed. Two distinct breaks under Win2000, despite the commit message claiming "verified unchanged by render":

1. **Lost 4px sizing frame** (M) — the 2-DIP AltRaised bevel now paints over the caption's outer 2px and the 2px face strip is gone. Fix: token-driven `Bevel.Metric.CaptionMargin` (Win2000 `4,4,4,0`, Luna `0`) bound at `Window.axaml:53`; regen via ThemeGen. Restores classic `SM_CXSIZEFRAME=4`: 2px bevel + 2px face before the caption. Luna untouched.
2. **4px caption→client band instead of 1px** (S) — `WindowContentInset "4" → "4,1,4,4"` in `theme.json:96`. Total top chrome returns to 2+2+18+1 = 23px.

Do both together, with the **headless pixel-sampling render test a967ec8 lacked** (bands at x=0..5, captionMidY). Related follow-ups in the same files: maximized-state cleanup (2px backdrop ring + side insets, S) and wiring `Bevel.Metric.CaptionHeight` through `AutoAttachTitleBar` (S — unblocks Flat's 26px caption and removes a silent vendored-default dependency).

## BIG BETS

1. **Watercolor Flat theme ("Whistler Watercolor")** — spec is done (`docs/design/flat/flat-theme-spec.md`); tokens (M) + wash brushes (M) + the XL ControlTheme set + icon-palette override (M) + tests (M). The first proof that Bevel is a *platform* for skins, not two themes.
2. **Explorer Bar system** (XL) — Folders / Search / History / Favorites as interchangeable left bars; resolves the InfoPane-vs-tree either/or hack into the actual Win2000 architecture. Stage it: host generalisation → Favorites → Search → History.
3. **The derivation engine** — accent picker (M) → WCAG TextOn (M) → state derivation (M) → single-source surfaces via ThemeGen (M) → **derived dark mode (XL)**, the capstone: every scheme/accent/theme gets a dark twin for free. Order-of-engines (dark applies last, Clear() symmetry) is the hard part.
4. **The theme lineage** — Win10 flat (L, best effort/impact), Breeze (L, first non-Windows), Aero (XL, painted glass), Win11 (XL, build last, gated on taskbar centring + honest window template).

### Sequencing logic in one paragraph

Weeks 1–2 are the regression fix plus the S-tier quick wins (items 1–4, 6–7 of the Top 10) — they repair credibility and honor the "no hiding" rule. In parallel, land the two enablers (TypeToFind service, StartMenu brush contract) and the tokenization groundwork, because every later stream — type-to-find consumers, the accent picker, Flat, dark mode — is blocked behind them. Then the M-tier config/feature wave (single-click, view memory, MRU, tasks pane, Favorites, accent picker). The big bets run as three parallel tracks after that: Flat theme (spec-complete, start anytime after the enablers), the Explorer Bar system (stage-shippable), and the derivation chain culminating in dark mode. New skins (Win10 → Breeze → Aero → Win11) start only once the accent engine and brush contract have shipped and the window template is regression-free.
