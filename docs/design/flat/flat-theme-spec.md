# Bevel "Flat" theme — design spec (Whistler Watercolor, designed in 2026)

> Status: design spec, implementation-ready. Not code. The current `flat` theme
> (`src/Bevel.Themes.Win2000/ThemeFlat.axaml`) is a token-only stub that flips edge
> rendering + a few metrics; this document specifies the real theme that replaces it.
> Cross-refs: token system `src/Bevel.Themes.Win2000/Tokens.axaml` + `theme.json`
> (generated by `tools/ThemeGen`); the reference full theme is Luna
> (`src/Bevel.Themes.Luna/LunaTheme.axaml` + `LunaTokens.axaml`); engine + metrics in
> `docs/spec/05-theming.md` (§1–§3, ENG-01..07, MET-01); shell surfaces in
> `07-shell-ux.md`.

---

## 0. What this theme is, architecturally

Today `flat` is a **token-only** theme: `ThemeService.SourceFor("flat")` merges one
override dictionary over the base Win2000 tokens and reuses the Classic control
templates. That cannot express watercolor chrome (soft gradients, rounded soft
frames, painterly washes). This spec promotes `flat` to a **Styles-set theme like
Luna**: it ships its own `Bevel.Themes.Flat` project with

- `FlatTokens.axaml` — palette + metric overrides (the §2/§5/§7 values), same shape as `LunaTokens.axaml`;
- `FlatTheme.axaml` — a `Styles` set that merges `FlatTokens.axaml`, defines the watercolor gradient brushes (`Flat.Brush.*`), and re-templates controls via the shared `Bevel.Theme.*` contract keys (`Bevel.Theme.Button`, `.CheckBox`, `.RadioButton`, `.ProgressBar`, `.Slider`, `.TabItem`, `.ComboBox`, `.ToggleButton`, `.StartButton`, `.MenuItem`, …).

Wire it in `ThemeService.StylesFor`: `"flat" => "avares://Bevel.Themes.Flat/FlatTheme.axaml"`,
and drop the token-only `SourceFor("flat")` entry. Everything below is expressed as
`Bevel.*` semantic tokens or `Flat.Brush.*` locals bound through `{DynamicResource}`
(ENG-01) so it swaps live and stays recolorable. **Antialiasing is ON**
(`edgeRendering: Smooth`, `FontAliasingKey = False`); every fill is a vector gradient,
never a bitmap.

## 1. Concept & feel

**Watercolor, designed in 2026.** The soul is the early Windows "Whistler" (XP beta)
*watercolor* visual style: gentle pigment washes, luminous pastels, low-contrast
painterly gradients, soft rounded chrome, a light and airy room. That style was killed
before it shipped and only ever existed as low-fidelity beta bitmaps. Bevel takes the
*idea* — pigment settling on warm paper — and executes it at maximum modern quality:
smooth multi-stop gradients with no hard specular split, soft diffuse shadows, hairline
low-contrast borders, generous breathing room, everything vector-crisp at any DPI. It is
not a flat-design "Metro" theme and not a glass/blur theme; "flat" here means *matte* —
the opposite of Luna's wet gloss — with soft depth from wash and shadow rather than
bevels or beads.

**The mood** is calm, warm, and quiet. Surfaces are a warm off-white *paper*, not grey.
Chrome neutrals carry a faint cool lilac bias so they read as "pale," never "dead grey."
Accents are pastel pigments — sky-aqua, coral bloom, sage, butter, lilac — kept
deliberately desaturated and close in value, so the whole desktop sits in a narrow,
restful tonal band. Type is a soft near-black with a violet-grey bias; there is no pure
`#000000` and almost no pure `#FFFFFF` in the chrome, because watercolor has neither.

**What makes it distinct** from its two siblings: Win2000 is crisp, aliased, high-contrast
classic (grey faces, hard 3-D bevels, square corners); Luna is glossy, saturated XP blue
(wet specular beads, hard 50% highlight splits, taller chrome). Flat is the third
identity — **softer, lighter, painterly**: matte pastel washes instead of gloss, larger
soft corner radii, hairline borders instead of bevels or dark outlines, soft diffuse
shadows, and — its signature move — **dark ink text on light pastel chrome** (caption,
taskbar, selection) where the others use white text on dark saturated fills. The desktop
reads like tinted paper rather than a painted machine.

## 3. Gradients & washes

The signature is a **soft bloom wash**: multi-stop, low-contrast, *no hard offset-pair
split* (Luna's `0.5 / 0.5` glossy bead is explicitly avoided). Pigment is lighter at the
top edge, settles to a deeper but still-desaturated base, like water drying on paper.

**Caption (active) — the signature wash.** Vertical, soft:
```
0.00  #D6EEF7   (paper-thin sky sheen)
0.30  #B4DEEE
0.62  #9BD0E5
1.00  #86C3DA   (Wash Sea — settled pigment)
```
Optional painterly refinement (tasteful, not required): a very faint warm **bloom overlay**
`Flat.Brush.CaptionBloom` — a `RadialGradientBrush` anchored top-left, `#22F4C9CE` → `#00F4C9CE`
— so one corner carries a whisper of coral, the way a wet wash pools unevenly. Keep alpha ≤ `0x22`.

**Caption (inactive):** muted, near-neutral — `#E4EAF0` → `#CDD8E2`.

**Button face (matte wash):** vertical, very soft, paper→mist:
```
0.00  #FCFAF6
0.50  #F3EFF6
1.00  #E7DFF0
```
**Button hover (warm butter bloom):** `#FFFDF3` → `#FBF1D6` → `#F6E7C8`.
**Button pressed (gentle sink):** `#E2DAEC` → `#EEE9F4` (top slightly darker; no bevel flip, no +1,+1 content shove — instead a 1px content nudge is optional and subtle).

**Taskbar (airy aqua bar):** vertical, pale, shallow-concave like Luna's shape but
pastel and low-contrast — a soft bright edge top and bottom, a wide slightly-deeper middle:
```
0.00  #CFEBF4
0.06  #BFE1EE
0.50  #ADD6E8
0.94  #BFE1EE
1.00  #CFEBF4
```
Tray text and clock are **Ink** (`#3A3550`) — dark on the light bar (the inverse of Luna).

**Tray well (inset):** a touch deeper aqua so it reads as recessed without a bevel —
`#A9D6E8` → `#9BCDE2` → `#A9D6E8`, flat border (0), delineated by color contrast alone.

**Selection / highlight bar:** soft aqua wash `#BCE3F2` → `#A0D2E8`, **Ink** text.

**Start pebble bloom:** `#C7E7C4` → `#A6D6A8` → `#8FC79A` (sage), hover warms toward
`#D6EFCF` → `#B6E0B2`.

**Progress fill:** *continuous* soft aqua-sage wash (watercolor flows, so no discrete
blocks like Win2000/Luna) — `#BFE6DC` → `#9AD6C4` → `#86C7B4`, in a pale field well.

**Field well (textbox/combo/check):** faint top inset → paper → white:
`#F4EFF8` (0.0) → `#FCFAF6` (0.15) → `#FFFFFF` (1.0).

## 4. Chrome treatment per surface

General rules that give the theme its character: **corner radii are larger and softer**
than Luna; **borders are single hairlines in Edge `#C9BFD6`**, never 3-D bevels or dark
outlines; **shadows are soft and diffuse** (large blur, low alpha ~`#22`–`#28`), never
tight/dark; there are **no specular gloss strips**.

### Window frame + caption
- Frame: a 1px `WindowFrame` = `#B9C7D6` (soft blue-grey) hairline; content border
  `1,0,1,1` (thin, like Luna's 3-side wrap but 1px and pale), `WindowContentInset` `0`.
- Caption: height **26**; fill = `Bevel.Brush.CaptionActive` (the §3 wash), text **Ink**,
  left-aligned, medium weight, after the 16px window icon (caption padding `12,0,4,0`).
  Top corners rounded **10px** (`CornerRadius 10,10,0,0`), bottom square.
- Wire like Luna: set `Bevel.Brush.CaptionActive/Inactive`, the `SystemColors.*Caption*`
  keys, and `SystemParameters.WindowCaptionHeightKey = 26` so the vendored
  `AutoAttachTitleBar` picks up the wash + height without a re-template. Remap
  `SystemColors.ControlBrushKey` to **Paper** so frame/caption gaps blend (Luna does this
  with beige).
- Caption buttons: **20×20**, soft **6px** rounded squares, matte (no gloss bead). Minimize/
  restore/maximize carry a thin Ink glyph on a translucent Mist face; **close** uses the
  Petal/Bloom wash (`#E39AA1`→`#F4C9CE`) with a white glyph. Hover = gentle lightening +
  a soft 1px Edge ring; pressed = `Opacity 0.85`. Re-template `{x:Type CaptionButtons}` as
  Luna does.

### Buttons (dialog / push)
- Face = `Flat.Brush.Button`, border 1px `Flat.Brush.ButtonBorder` (`#C7BBD8`),
  `CornerRadius 6`, `MinHeight 24`, padding `12,4`. No gloss strip.
- Default button: a soft **aqua** ring — an outer `Border` (radius 8, padding 1) whose
  `BorderBrush` becomes `#8FBFD8` when `IsDefault` (the airy analogue of Luna's blue
  double-frame), plus a faint outer glow via a low-alpha `BoxShadow`.
- Hover: `Flat.Brush.ButtonHover` (butter bloom) + border warms to `#E8C98F`.
- Pressed: `Flat.Brush.ButtonPressed`; content nudges `translate(0,1px)` (subtle).
- Disabled: face flattens to Mist, text → Ink Soft, border → Edge.
- Focus: a soft **2px rounded** aqua ring inset (`FocusRectInset 2`), *not* the Win2000
  marching-ants dotted rect — painterly, not pixel.

### Selection / highlight
- Anywhere a selection bar appears (menu item, list row, start-menu row): the soft aqua
  wash (`#BCE3F2`→`#A0D2E8`), `CornerRadius 3`, **Ink text retained**. Hot-tracking links
  use Wash Sea `#4E9BBE` (a readable aqua).

### Menus (menu bar, dropdown, context)
- Menu bar item: transparent → on hover a soft Mist rounded patch (radius 3); open = the
  aqua selection wash. Text Ink.
- Dropdown / context popup: **Paper** item area, a soft **Mist gutter** (24px, left) for the
  icon column, `MenuBorder` 1px `#C9BFD6`, `CornerRadius 8`, and a **soft diffuse shadow**
  `BoxShadow="0 4 16 0 #26000000"` (larger + softer than Luna's `0 2 7 #35000000`).
- Separator: a single thin `#E0D8EA` line inset to the item area (starts past the gutter),
  not a full-width etched double line.
- Item selection: aqua wash bar, Ink text; disabled = Ink Soft.

### Taskbar
- Background = `Bevel.Brush.TaskbarBackground` (the §3 airy aqua wash); height **34**
  (airier than Luna's 30). No raised 3-D strip.
- Task buttons (`Bevel.Theme.ToggleButton`): matte Mist-paper wash pebble, `CornerRadius 6`,
  1px Edge border, Ink text; hover = butter bloom; **`:checked` (active window)** = the aqua
  selection wash (a gentle *fill*, not a sunken bevel) with a slightly stronger border.
- Dividers: transparent (like Luna — the color contrast separates regions; no 3-D seams).
- Tray well: §3 inset aqua; tray/clock text Ink.

### Start button & Start menu
- Start button (`Bevel.Theme.StartButton`, set locally on the taskbar button): a soft
  **sage pebble** — fully rounded lozenge (`CornerRadius 14` / capsule), `Flat.Brush.Start`
  bloom, border `#86B98C`, label in **deep moss ink `#2E4A34`** (airy; not white),
  medium-weight, *not* italic (Luna's italic is an XP signature — flat stays upright).
  Flush to the screen edge (`StartButtonMargin 0`).
- Start menu: see §6.

### Inputs, tabs, scrollbars, progress, slider (summary)
- TextBox/ComboBox/CheckBox/Radio wells: `Flat.Brush.Field`, 1px Edge border, `CornerRadius 3`
  (fields) / `4` (combo). Check tick = 2px round-cap stroke in Wash Sea `#5AA7C4`; radio dot =
  aqua Highlight. Focus = aqua ring, matching buttons.
- Tabs: `CornerRadius 6,6,0,0`, unselected soft Mist, selected **blooms to Paper** (soft
  vertical `#FFFFFF`→`#FBF7F1`) and lifts 1px — no hard bevel.
- ScrollBar: 15px; track = pale Mist `#F2EEF7`; thumb = soft Mist-lilac wash pebble
  (`CornerRadius 5`) with three faint Ink-Soft grip dots; arrow buttons matte, Ink glyphs.
- ProgressBar: pale field well, `CornerRadius 4`, **continuous** aqua-sage wash fill (§3),
  soft.
- Slider: 4px rounded track, filled (decrease) side in soft aqua Highlight, thumb a soft
  Mist pebble `CornerRadius 4`.
- GroupBox: 1px soft `#DCD3E6` rounded frame, header label knocks out on Paper.
- Tooltip: `InfoWindow` = warm **`#FFF8E6`** (butter-cream, not classic `#FFFFE1`), 1px
  `#E7D8B0` border, `CornerRadius 4`, Ink text, soft shadow.

## 5. Typography & metrics

- **Antialiasing ON** — `edgeRendering: Smooth`; `SystemParameters.FontAliasingKey = False`
  (subpixel AA), matching Luna, opposite of Win2000's aliased look. Watercolor is a smooth
  era; crisp aliased type would fight the soft chrome.
- Fonts: reuse the shared `Bevel.Font.UI/.Caption/.Mono` families (Bevel Sans / Noto Sans /
  mono). No new faces needed. Caption is **medium weight, upright** (not bold-italic).
- Metrics (a new "Flat" column for `theme.json` / MET-01), airier than Win2000/Luna:

| Key | Flat | (Win2000 / Luna) | Why |
|---|---|---|---|
| `CaptionHeight` | **26** | 18 / 25 | roomier, airy |
| `CaptionButtonWidth×Height` | **20×20** | 16×14 / 21×21 | soft rounded squares |
| `EdgeThickness` | **1** | 2 / 1 | hairline, no 3-D edge |
| `ScrollBarSize` | **15** | 16 / 17 | slightly slimmer |
| `MenuBarHeight` | **21** | 19 / 20 | breathing room |
| `MenuItemHeight` | **21** | 17 / 18 | airy rows |
| `TaskbarHeight` | **34** | 28 / 30 | the airiest bar |
| `CornerRadius` | **10,10,0,0** | 0 / 8,8,0,0 | softest of the three |
| `FocusRectInset` | **2** | 1 / 1 | soft ring, not dotted |
| `ButtonPadding` | **12,4** | 6,1 / 8,2 | generous |
| `WindowContentBorder` | **1,0,1,1** | 0 / 3,0,3,3 | thin pale frame |
| `CaptionPadding` | **12,0,4,0** | 2,0,2,0 / 11,0,3,0 | inset from rounded corner |

MET-02 large-fonts (×1.25) applies to `MenuItemHeight`/`CaptionHeight` as elsewhere.

## 6. Start menu recommendation

**Use the two-column layout** (the modern XP-style panel already in
`StartMenu.axaml` — header + pinned/places columns + footer). Its airy, welcoming shape
suits watercolor far better than the austere Win2000 single column with the rotated navy
banner. But do **not** reuse the Luna one as-is: that tree hardcodes `Luna.Brush.StartMenu*`
keys, which are XP-blue-coded.

Recommended (on-architecture, least duplication): **promote the start-menu palette to a
theme-neutral contract** — rename the `Luna.Brush.StartMenu*` keys used by the two-column
tree to `Bevel.Brush.StartMenu*` (per ENG-01/ENG-03), have both Luna and Flat provide
values, and let the `StartMenu` code-behind show the two-column layout whenever
`ThemeService.Current` is `luna` **or** `flat`. Flat's values:

- Header band: soft aqua wash (`#BFE0F0`→`#86C3DA`), **Ink** user name (not white).
- Header rule: replace Luna's orange band with a soft **Bloom** hairline (`#F4C9CE` +
  lighter `#FBE4E7`) — the one warm accent.
- Pinned column: **Paper**; place column: pale **Lilac-mist** (`#EDE7F6`→`#E3DAF0`).
- Row hover: the aqua selection wash, Ink text (keep flat's dark-on-pastel rule; override
  the Luna tree's `:pointerover TextBlock → White` to Ink for the flat case).
- Footer band: soft sage (`#BFE3C4`→`#8FC79A`), Ink labels; Log Off / Turn Off icon chips
  in Bloom and Petal.
- Avatar tile: a soft Butter→Bloom diagonal bloom.
- Panel: `CornerRadius 10`, 1px `#B9C7D6` border, soft diffuse shadow.

Fallback if promoting the contract is out of scope for the milestone: add a third
`FlatLayout` sibling `Border` in `StartMenu.axaml` (same structure, flat tokens) toggled
by `ThemeService.Current == "flat"`. Same visual result, more markup duplication —
prefer the contract promotion.

## 8. What to avoid (watercolor without the AI slop)

- **No purple-indigo default gradient.** The #1 AI-slop tell. The lilac here is a *pale
  neutral bias* and a minor decorative accent, never a saturated hero gradient. The heroes
  are aqua and sage.
- **No rainbow / high-saturation washes.** Keep every pigment desaturated and close in
  value; the whole palette lives in a narrow tonal band. If a gradient looks "vivid," it's wrong.
- **No fake paper texture, no visible brush strokes, no grain/noise overlays.** The
  "watercolor" is carried by soft *gradients and value*, not a bitmap texture — and assets
  must stay vector (keep-assets-vector rule). A canvas-texture PNG would read as kitsch and
  break DPI crispness.
- **No glossy specular beads or hard 50/50 highlight splits.** That is Luna's language;
  flat is matte. No wet-plastic sheen strips.
- **No neumorphism / heavy dual drop-shadows**, and no glassmorphism blur. Depth comes
  from one soft diffuse shadow + gentle wash, nothing more.
- **No pure `#000` text or pure `#FFF` chrome fills.** Watercolor has neither; use Ink and
  Paper. (White is fine only as a field-well interior and a gradient's lightest sheen stop.)
- **Don't over-round into all-pills.** Soft radii, yes; but only the Start button is a full
  capsule. Buttons/menus/tabs keep modest 3–8px radii so the shell still reads as a classic
  desktop, not a mobile toy.
- **Keep the classic-shell bones.** Taskbar at the bottom, Start at the left, menu bars,
  two-pane file manager — the watercolor is a *finish* on the Win2000/XP structure, not a
  redesign of the layout. Fidelity = colours + feel + function, reimagined; not a new OS.
